# プロジェクトのカスタマイズと商用化

本ガイドでは、本プロジェクトを独自のゲームへリブランドする方法、ゲームのジャンルやトーンを変更する手順、およびSteam、itch.io、Godot Asset Store等で販売するための準備について解説します。

---

## 1. 2つの配布・販売モデル

本プロジェクトは2通りの方法で収益化またはリリースが可能です：

### モデルA：プレミアムテンプレート／商用ゲームエンジンとして販売（Godot Asset Store、GitHub等）
- Godotプロジェクト一式、Webエディタ（`editor/`）、およびドキュメント（`docs/guide/`）を同梱してパッケージングします。
- 購入者はWebエディタを使用して独自のRPGやストーリーを構築できます。
- 提供内容：
  1. `docs/guide/`（全言語または英語＋母国語）
  2. `editor/`（Webエディタ）
  3. 完全なGodotプロジェクトソース
  4. 事前定義されたデフォルトデータ（スターターテンプレート）

### モデルB：独立したスタンドアロンゲームとして販売（Steam、itch.io、コンソール等）
- あなた自身がWebエディタを使って制作した「完成版ゲーム」のみを配布します。
- エクスポート時には開発用ツール（F1デバッグコンソール、Webエディタ、開発用データ編集機能）を無効化または除外します。

## 2. リブランド（名称・タイトルの変更）

### 2.1 ゲームタイトルとバージョン
[project.godot](file:///d:/workspace/ods-proy-godot/project.godot) を開いて編集します：

```ini
[application]
config/name="あなたのゲームタイトル"
config/version="1.0.0"
config/description="あなたのゲームの説明文"
```

### 2.2 ウィンドウ設定と解像度
同じく [project.godot](file:///d:/workspace/ods-proy-godot/project.godot) 内：

```ini
[display]
window/size/viewport_width=1280
window/size/viewport_height=720
window/size/mode=0              ; 0: ウィンドウ, 3: フルスクリーン
window/stretch/mode="canvas_items"
window/stretch/aspect="keep"
```

### 2.3 ウィンドウアイコンと実行ファイルアイコン
1. アイコン画像（256x256のPNG）を用意し、`icon.png` または `assets/icons/app_icon.png` に配置します。
2. [project.godot](file:///d:/workspace/ods-proy-godot/project.godot) で指定：
   ```ini
   config/icon="res://icon.png"
   config/windows_native_icon="res://assets/icons/app_icon.ico"
   ```

## 3. ジャンルとテーマの変更

本プロジェクトはサイバーパンク・ディストピア調のデフォルト設定を持っていますが、データとアセットを差し替えることで任意のジャンル（中世ファンタジー、現代ホラー、Sci-Fiスペースオペラ、日常ミステリー等）に変更可能です。

### 3.1 中世ファンタジー化の例
- **ゾーン**：スラム街 → 「王都下町」「エルフの森」「薄暗い迷宮」
- **敵**：サイバードローン → 「ゴブリン小隊」「巨大クモ」「スケルトンキング」
- **スキル**：オーバークロック → 「バーサーク」「治癒の光」「ファイヤーボール」
- **アイテム**：ナノインジェクター → 「回復ポーション」「解毒ハーブ」
- **能力値名称**：`data/i18n.json` で表記を調整（例：メモリ → 魔力）。

### 3.2 最小変更ステップ
1. `data/zones.json`：ゾーン名と解説文を変更。
2. `data/pois.json`：POI（拠点・ダンジョン・店）と対話ツリーを差し替え。
3. `data/enemies.json`：敵モンスターの構成を変更。
4. `assets/`：背景・スプライト・ポートレート・BGMを差し替え。

## 4. UI・カラーパレットのカスタマイズ

### 4.1 UIテーマ設定
ゲーム全体のテーマは [assets/themes/](file:///d:/workspace/ods-proy-godot/assets/themes/) のGodot `.theme` リソースで制御されています。
- Godotエディタでテーマファイルを開き、フォント、パネルの背景色（StyleBoxFlat）、ボタンホバー時のアクセントカラー等を一括変更できます。

### 4.2 Webエディタのカラーパレット
エディタのビジュアルは [editor/css/editor.css](file:///d:/workspace/ods-proy-godot/editor/css/editor.css) 内のCSS変数で定義されています：

```css
:root {
  --bg-primary: #0a0e17;      /* メイン背景色 */
  --accent-cyan: #00f3ff;     /* ネオンアクセント（ファンタジーなら金色 #ffd700 等に変更） */
  --accent-purple: #bc13fe;   /* サブアクセント */
  --text-main: #e2e8f0;       /* 本文テキスト */
}
```

## 5. 多言語ローカライズの調整

ゲーム内でサポートする言語を絞る、または追加したい場合：

1. `data/i18n.json` 内の対応言語キーを整理。
2. [scripts/managers/I18nManager.gd](file:///d:/workspace/ods-proy-godot/scripts/managers/I18nManager.gd) のサポート言語リスト（`SUPPORTED_LOCALES`）を更新：
   ```gdscript
   const SUPPORTED_LOCALES = ["es", "en", "ja"] # 例：3言語に限定する場合
   ```
3. 設定画面（SettingsScreen）の言語切り替えドロップダウン選択肢を調整。

## 6. リリース前チェックリスト

- [ ] **全JSONデータの整合性検証**：`python tools/validate_data.py` を実行してエラー0を確認。
- [ ] **開発用チート・デバッグの非表示**：
  - [scripts/ui/DebugConsole.gd](file:///d:/workspace/ods-proy-godot/scripts/ui/DebugConsole.gd) のF1ショートカットを商用ビルドで無効化。
- [ ] **クレジット画面の更新**：[scenes/ui/credits/CreditsScreen.gd](file:///d:/workspace/ods-proy-godot/scenes/ui/credits/CreditsScreen.gd) にあなたの名前やクレジット、ライセンス表記を記載。
- [ ] **BGM・効果音ライセンスの確認**：使用している全オーディオ素材の商用利用条件をクリアしているか再点検。
- [ ] **セーブデータの移行テスト**：新規セーブ作成、スロット間の上書き、読み込みが正常に動作することを確認。
