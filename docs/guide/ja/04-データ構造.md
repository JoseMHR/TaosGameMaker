# 04 — データ構造 (`data/`)

ゲームの全データは `data/` 直下にJSON形式で格納されています：

- **`kind: 'doc'`**：1つのJSONファイルに辞書形式で集約（例：`professions.json`, `config.json`, `quests.json`）。
- **`kind: 'perId'`**：IDごとに1つの独立したJSONファイルを配置（例：`enemies/<id>.json`, `npcs/<id>.json`, `dungeons/<id>.json`）。

---

## 1. ネイティブ7言語ローカライズ辞書

プレイヤーに表示されるすべてのテキストは、以下の7つの公式キーを持つ辞書オブジェクトとして保持されます：
- `ja`（日本語）
- `en`（英語）
- `es`（スペイン語）
- `fr`（フランス語）
- `it`（イタリア語）
- `de`（ドイツ語）
- `zh`（簡体字中国語）

記述例：
```json
"text": {
    "ja": "酒場へようこそ！",
    "en": "Welcome to the tavern!",
    "es": "¡Bienvenido a la taberna!",
    "fr": "Bienvenue à la taverne !",
    "it": "Benvenuto alla taverna!",
    "de": "Willkommen in der Taverne!",
    "zh": "欢迎来到酒馆！"
}
```

## 2. 報酬トークン言語 (`reward`)

セミコロン `;` で区切られた命令列として記述され、会話ノードやイベントで実行されます：

| トークン | 記述例 | 実行内容 |
|---|---|---|
| `gold` | `gold:±N` | 所持金の増減 |
| `xp` | `xp:N` | 経験値の付与 |
| `heal` | `heal` | 全員のHP・MPを全回復 |
| `damage` | `damage:N` | 戦闘外ダメージ（最低1HPを保持） |
| `item` | `item:ID=N` | アイテムの獲得 |
| `-item` | `-item:ID=N` | アイテムの消費・没収 |
| `flag` | `flag:NAME` | 現在のNPC専用のローカルフラグを設定 |
| `gflag` | `gflag:NAME` | 永続的なグローバルストーリーフラグを設定 |
| `questf` | `questf:STATE` | メインクエストをその状態へ前進 |
| `prof` | `prof:ID` | クラスの解放と即時転職 |
| `combat` | `combat:enemy_id[:level]` | 戦闘エンカウントの発生 |
| `cine` | `cine:ID` | 指定のカットシーンを再生 |

---

## 3. 条件式構文 (`condition`)

実行時に動的評価される論理式：
- `has_flag("X")` / `no_flag("X")`：NPCローカルフラグの確認。
- `gflag("X")` / `has_gflag("X")`：グローバルフラグの確認。
- `has_item("id"[, qty])`：アイテム所持の判定。
- `gold >= 100`：所持ゴールドの判定。
- `quest == "dam_opened"`：メインクエスト進行段階の判定。
