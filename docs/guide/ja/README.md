# ⚔️ JRPG Complete Template & Engine — 日本語ユーザーガイド

> **Godot 4 向けプロフェッショナル JRPG テンプレート＆ゲームエンジンへようこそ。**  
> 本プロジェクトは、完成された商用クオリティのゲーム（3D見下ろし型ワールドマップ、一人称視点グリッド型ダンジョン、ターン制タクティカルバトル、ビジュアルノベル風の会話劇）と、専用の**ローカルビジュアルWebエディタ**を融合させたものです。コードを1行も書くことなく、あなた自身のゲームを自由に作成・変更・バランス調整できます。

---

## ⚡ クイックスタート（3分で起動）

データベースの設定や複雑なビルド手順は一切不要です：

### 1. 動作環境
- **Godot Engine 4.3+**（Standard版・.NET版どちらでも動作可能）。
- **Python 3.8+**（macOS/Linuxには標準搭載。Windowsは [python.org](https://www.python.org/) から入手可能）。

### 2. Godotで開いてプレイする
1. **Godot Engine** を起動し、**インポート (Import)** をクリックします。
2. 本ディレクトリ内の `project.godot` ファイルを選択します。
3. **プロジェクトを実行 (Run Project)**（または `F5` キー）を押します。メインメニューが起動します！
   - 全コンテンツを一括確認したい場合は、メニュー内の **デバッグモード / テストルーム (Debug Mode / Test Room)** を選択してください。

### 3. Webコンテンツエディタを起動する
エディタはローカルWebアプリであり、`npm` やビルドツールは不要です：
1. プロジェクトのルートディレクトリでターミナルを開きます。
2. 以下を実行します：
   ```bash
   python editor/serve.py
   ```
3. ブラウザでアクセスします：
   👉 **[http://localhost:8000](http://localhost:8000)**

Webエディタで保存したすべての変更（敵、マップ、会話など）は、**エンジンを再起動することなく即座にGodotに反映されます**。

## 🎮 本テンプレートに含まれる要素

### 🗺️ 4つの完全統合型ゲームプレイ
1. **3D見下ろし型ワールドマップ**：六角・四角グリッド、戦場の霧、バイオーム、環境気象、永続的な世界変容（伐採可能な木、粉砕可能な岩、設営可能なキャンプ）および航行可能な船。
2. **一人称視点ダンジョン探索 (3D Dungeon Crawler)**：動的ミニマップ、鍵付きドア、パズルギミック、宝箱、ボス戦を備えたグリッド移動式3Dダンジョン。
3. **ターン制タクティカルバトル**：属性相性計算、状態異常、ATBゲージ、アクションポイント (AP) スキルキューイング、クラス連携シナジー、ダイナミックカメラ演出。
4. **ノベル式ストーリー＆対話**：分岐選択肢ツリー、表情豊かな立ち絵、環境適応BGM、クエスト管理、永続グローバルフラグ。

### 🛠️ ノーコード対応ビジュアルWebエディタ
ブラウザで動作する完全なゲーム制作スイート：
- **3Dワールドマップエディタ**：クリック操作で地形の描画、街、ダンジョン、採取ノード、敵、宝箱を配置。
- **ダンジョンレベルデザイナー**：3Dグリッド構造の編集、リアルタイムテクスチャ確認、ステップ実行ウォークスルーシミュレータ (*DungeonWalkthroughModal*)。
- **敵・スキルビルダー**：基礎ステータス、行動AI、ドロップ率を設定し、ブラウザ上で直接対戦テストができる **Combat Sandbox (戦闘サンドボックス)** を内蔵。
- **会話・クエストツリーエディタ**：視覚的なノードグラフエディタ (*NpcGraphEditor*) とリアルタイムノベルシミュレータ (*VnSimulator*)。
- **タレントツリー・クラス・シナジー**：充実した成長曲線のバランス調整。
- **ワンクリック作成ウィザード**：ダンジョン骨組み、クエスト、アイテム、NPC付き拠点を即座に自動生成。
- **ネイティブ7言語対応**：日本語、英語、スペイン語、フランス語、イタリア語、ドイツ語、中国語（簡体字）を完全統合。

### 🧪 テストルーム＆デバッグワールド
- 8つのパビリオンで構成されたテスト世界 `data/world_test.json` を同梱。ゲーム内の**すべての拠点 (162箇所)、都市 (4つ)、ダンジョン (13箇所)、敵 (41種) を100%** その場でテスト可能です。

## 💡 基本方針

> **「JSONで記述できるものは、決してコード内にハードコードしない」**

本テンプレートを用いたゲーム制作は、安定したGDScriptコアエンジンには触れず、**Webエディタを通じて `data/` 内のJSONデータを編集・差し替える**だけで完結します。
