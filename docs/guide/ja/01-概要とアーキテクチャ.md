# 01 — 概要とアーキテクチャ

## 1. 本テンプレートの定義

本プロジェクトは、単なる未完成のフレームワークではなく、**即座にプレイ可能な本格JRPG**（`project.godot` での内部識別名は "Taos Game Maker"）と、**専用設計のコンテンツエディタ**が一体となった製品です。コアエンジンの **80〜90%（戦闘、ダンジョン探索、会話、セーブ、アイテム、成長システム）をそのまま再利用**し、**クリエイティブなコンテンツ**（ストーリー、敵、マップ、グラフィック、楽曲）を差し替えるだけで、あなただけのゲームを完成させることができます。

### 4つの独立ゲームプレイ＋1つの基幹システム
- 🗺️ **ワールド (World)**：3D見下ろし型マップ、資源採取、野営・料理、船舶航行 (`TabWorld3D.gd`)。
- 🏰 **ダンジョン (Dungeons)**：一人称視点3Dグリッド探索、6大スキルギミック (`ViewDungeon.gd`)。
- ⚔️ **戦闘 (Combat)**：JRPGターン制ATBバトル、APスキルキューイング、連携シナジー (`ViewCombat.gd`)。
- 📖 **物語 (Narrative)**：ビジュアルノベル、分岐選択肢グラフ、街施設、NPC (`ViewPlace.gd`)。
- ⚙️ **基幹システム**：装備経済、ショップ、実績、数値バランス (`Autoloads`)。

---

## 2. 技術スタック

- **ゲームエンジン**：Godot 4.3+、GDScript、`mobile` レンダリング方式、ネイティブ 3D 物理演算。
- **対応プラットフォーム**：デスクトップ (Windows, macOS, Linux) および モバイル (Android, iOS)。
- **Webエディタ**：Vue 3（CDN経由、ビルド不要、npm等の事前導入なしで即起動可能）。
- **ローカルサーバ**：Python 3 標準ライブラリ (`editor/serve.py`)。
- **データ永続化**：`data/` ディレクトリ下のプレーンテキスト JSON。

---

## 3. Godot オートロード単例 (Autoloads)

`project.godot` 内の `[autoload]` に定義され、全スクリプトからグローバルにアクセス可能：
- `Locale` (`scripts/autoload/Locale.gd`)：7言語（日本語、英語、スペイン語、フランス語、イタリア語、ドイツ語、中国語）の即時切り替え、文字サイズ調整、色覚サポート。
- `Design` (`scripts/autoload/Design.gd`)：`data/` 内の全JSONのロード、パース、キャッシュ。
- `ExplorationSkills` (`scripts/autoload/ExplorationSkills.gd`)：ダンジョン探索用6大スキルのロジックと状態管理。
- `GlobalState` (`scripts/autoload/GlobalState.gd`)：プレイヤーステータス、ゴールド、所持品、装備、進行フラグ。
- `GlobalEvents` (`scripts/autoload/GlobalEvents.gd`)：疎結合なグローバルイベントバス。
- `SaveManager` (`scripts/autoload/SaveManager.gd`)：ゲームセーブデータの暗号化・復号化とスロット管理。
- `QuestManager` (`scripts/autoload/QuestManager.gd`)：クエスト進行管理とカットシーン呼び出し。
