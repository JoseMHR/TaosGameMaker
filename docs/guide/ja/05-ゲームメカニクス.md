# 05 — ゲームメカニクス（4大コアシステム）

詳細な計算式や内部仕様は `docs/design/` の各設計書をご覧ください。

---

## 1. 🗺️ 3D見下ろし型オーバーワールド
- タイル単位の移動、戦場の霧、動的な天候環境。
- **採取ツール体系**：木材には斧、鉱石にはツルハシ、釣りには釣竿、埋没物にはシャベル。
- **キャンプと料理**：テント設営で全員回復と時計進行；焚き火でバフ効果のある料理を作成。
- **ダイナミックな世界変容**：ストーリー進行フラグに応じたタイルのリアルタイム置換（ダム決壊、干上がった川の氾濫、荒野の緑化）。

---

## 2. 🏰 一人称視点3Dダンジョン
- ミニマップ連動のステップ式3Dグリッド移動。敵はビルボードスプライト表示。
- **6大探索スキル**：
  - 💥 衝撃波 (Kinetic Wave)：障害物の破壊、遠隔スイッチの作動。
  - ⭕ 念力ワイヤー (Psychic Grapple)：フック環や高所への跳躍。
  - 👁️ 狩人の瞳 (Hunter's Sight)：隠し扉や見えない床の看破。
  - 🔥/💧 元素共鳴 (Elemental Affinity)：松明の着火、氷の融解。
  - ☁️ 浄化の風 (Purify)：有毒ガスの除去、汚染水の浄化。
  - ⏳ 時空制御 (Chrono Warp)：移動床や時間制限扉の制御。

---

## 3. ⚔️ ターン制タクティカルバトル
- 伝統のサイドビュー形式：自陣が左、敵軍が右。
- **ATBゲージ＆APスキルキューイング**：ATB充填時、AP枠の許す限り複数のスキルを同一ターンに予約発動。
- **スキルシナジー**：特定の組み合わせ順序で連続発動させることで合体技へ昇華。
- **QTEアクティブガード**：敵攻撃時のタイミングリングにより被ダメージ軽減、またはパーフェクトガードによる完全無効化。

---

## 4. 📖 ノベル式対話＆街システム
- 16:9パノラマ背景 (`assets/vn/bg/`) とキャラクター立ち絵。
- **主人公の5大パーソナリティ**（勇気、慈愛、魅力、知性、正気度）：一定値以上で限定選択肢が開放。
- 7言語対応の選択肢ツリーから直接ショップや戦闘イベントへシームレスに遷移。
