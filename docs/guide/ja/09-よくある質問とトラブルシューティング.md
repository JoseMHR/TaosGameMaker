# よくある質問とトラブルシューティング (FAQ)

本章では、開発時やカスタマイズ時によくある疑問や発生しやすいトラブルとその解決策をまとめています。

---

## 1. Webエディタに関するトラブル

### Q1: ブラウザで `editor/index.html` をダブルクリックしてもデータが読み込まれない
- **原因**：ブラウザのセキュリティ制限（CORSポリシー）により、`file:///` プロトコル経由の直接ローカルJSONファイル読み込みがブロックされています。
- **解決策**：ローカルWebサーバー経由で起動してください。
  ```bash
  cd editor
  python -m http.server 8000
  ```
  ブラウザで `http://localhost:8000` にアクセスするか、VS Codeの「Live Server」拡張機能等をご利用ください。

### Q2: エディタで変更を保存したのにゲーム内に反映されない
- **原因**：ブラウザから自動保存されたファイルを、プロジェクトの `data/` フォルダへ上書き配置していない可能性があります。
- **解決策**：ブラウザのダウンロードフォルダに保存されたJSONファイルをプロジェクトルートの `data/` ディレクトリにコピー（上書き）してください。Godotエディタが開いている場合、自動的にファイル変更が検知・再ロードされます。

## 2. Godotエンジンとゲームプレイに関するトラブル

### Q3: POI（探索地点）に入っても背景画像やNPCポートレートが表示されない
- **原因**：
  1. 画像パスのスペルミスまたは拡張子の不一致（`.png` と `.PNG` は大文字小文字が区別されるプラットフォームがあります）。
  2. `assets/backgrounds/` または `assets/portraits/` に画像が配置されていない。
- **解決策**：
  - POI設定の `background` または `portrait` に指定したパス（例：`res://assets/backgrounds/bar.png`）が実在するか確認します。
  - 画像が存在しない場合、フォールバックとしてデフォルト背景が表示されます。

### Q4: 会話の選択肢をクリックしても何も起きない、または会話が途中で止まる
- **原因**：
  - 選択肢の `next_node` に指定されたノードIDが存在しない（タイプミス）。
  - `conditions` に未定義のフラグやクエストIDが指定されており、条件判定が常にfalseになっている。
- **解決策**：
  - Webエディタの「POIエディタ」のダイアロググラフ表示で孤立したノードがないか確認します。
  - `python tools/validate_data.py` を実行して、不正な `next_node` 参照を特定します。

### Q5: 戦闘が始まるとエラーで停止する、または敵の画像が表示されない
- **原因**：
  - エンカウント設定された敵IDが `data/enemies.json` に登録されていない。
  - 敵のアクション（AIルーチン）に指定されたスキルIDが `data/skills.json` に存在しない。
- **解決策**：
  - Webエディタの「戦闘サンドボックス（Combat Sandbox）」でその敵との戦闘をシミュレートし、ブラウザのコンソールでエラー内容を確認してください。

## 3. 多言語（i18n）に関するトラブル

### Q6: 一部の言語でテキストが英語またはスペイン語のまま表示される
- **仕様**：本プロジェクトの多言語システムは、現在選択されている言語のテキストが空文字列（`""`）またはキーが存在しない場合、自動的にデフォルト言語（英語またはスペイン語）へフォールバックする安全設計となっています。
- **解決策**：Webエディタまたは `data/i18n.json` で該当言語のキーに翻訳文を入力してください。

### Q7: 日本語や中国語の文字が「□（豆腐）」化して表示されない
- **原因**：UIテーマに割り当てられているフォントがCJK（日本語・中国語・韓国語）のグリフを含んでいない。
- **解決策**：プロジェクトにCJK対応フォント（Noto Sans JP, M PLUS 1p 等の `.ttf` または `.otf`）を導入し、[assets/themes/](file:///d:/workspace/ods-proy-godot/assets/themes/) のテーマファイルでフォントを指定してください。

## 4. セーブデータと永続化

### Q8: セーブデータはどこに保存されますか？
Godotの標準ユーザーデータディレクトリに保存されます：
- **Windows**：%APPDATA%\Godot\app_userdata\[ProjectName]\
- **macOS**：~/Library/Application Support/Godot/app_userdata/[ProjectName]/
- **Linux**：~/.local/share/godot/app_userdata/[ProjectName]/

テスト中にセーブデータを初期化したい場合は、ゲーム内の「設定 > データ初期化」を使用するか、上記フォルダ内の `save_*.json` を削除してください。
