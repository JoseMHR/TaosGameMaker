# 02 — クイックスタート

## 1. 必要な環境

- **Godot Engine 4.3+**
- **Python 3.8+**
- モダンなWebブラウザ（Chrome、Edge、Firefox等）

---

## 2. Godotでプロジェクトを起動する

1. Godot 4 を起動し、**インポート (Import)** をクリックして、プロジェクトのルートフォルダ（`project.godot` がある場所）を選択します。
2. 初回起動時、テクスチャや3Dモデルのインポート処理が行われます。
3. 右上の ▶️（または `F5` キー）を押すと、ゲームが起動します。

---

## 3. Webコンテンツエディタを立ち上げる

プロジェクトのルートフォルダでターミナルを開きます：

```bash
python editor/serve.py
```

実行すると、ブラウザが自動的に開き `http://localhost:8000/` が表示されます。

便利な起動オプション：
```bash
python editor/serve.py --port 8123      # ポート番号を指定
python editor/serve.py --no-open        # ブラウザを自動で開かない
```

---

## 4. 推奨する日常の開発ワークフロー

1. `python editor/serve.py` をバックグラウンドで起動しておきます。
2. ブラウザのエディタでデータ（モンスターの数値、ダンジョンマップ、会話ツリー）を編集し、**保存 (Save)** をクリックします。
3. Godotに切り替え、▶️ を押して実機テストを行います（Webサーバの再起動は不要です）。
4. Gitにコミットする前に、データ整合性チェックを実行します：
   ```bash
   python tools/validate_data.py
   ```
   存在しないIDの参照や破損を未然に検出できます。
