# 06 — アート・オーディオ・アセット

## 1. アセット格納構成 (`assets/`)

| ディレクトリ | 格納内容 |
|---|---|
| `assets/combat/` | 職業別キャラ (`character/`), 敵モンスター (`enemies/`), 戦闘背景 (`bg/`), スキルアイコン (`skills/`), VFX演出 |
| `assets/common/` | Cinzelフォント (`fonts/`), アイテム画像 (`items/`), 3Dモデル一式 (`models/`), BGM/SFX |
| `assets/dungeon/` | ダンジョン用の壁・床・天井テクスチャ (`textures/`) |
| `assets/vn/` | 16:9 背景イラスト (`bg/`) および NPC立ち絵 (`npcs/`) |
| `assets/world/` | ワールドマップの地形タイル画像 (`map/`) |

---

## 2. 基準解像度と規格

| アセット種別 | 拡張子 | 推奨解像度 | 特記事項 |
|---|---|---|---|
| **シーン背景 / POI画** | PNG / JPG | **1024×576** (16:9) | 全画面パノラマ。背景内に人物が直接描かれていても可。 |
| **戦闘アリーナ背景** | PNG / JPG | **1024×576** (16:9) | 戦闘用横長ステージ |
| **立ち絵 (NPC/敵/主役)** | PNG 32-bit RGBA | **512×512** | 透過アルファチャンネル必須 |
| **アイコン (アイテム/技)** | PNG 32-bit RGBA | **128×128** または **256×256** | 正方形アイコン |
| **3Dモデル** | `.glb` または `.obj` | スケール 1.0 = Godot 1単位 | `assets/common/models/` へ配置 |
| **楽曲 (BGM)** | `.ogg`, `.mp3`, `.wav` | ステレオ、ループ対応 | `AudioManager.gd` が再生制御 |

---

## 3. スプライト自動透過処理 (`tools/process_image.py`)

画像生成AI等で出力された単色背景付き立ち絵を、境界線の白浮きなく透過PNGに変換します：

```bash
pip install Pillow
python tools/process_image.py input.jpg output.png --type sprite
```
Webエディタのメディアライブラリ内の「画像を処理」ボタンからも直接実行できます。
