# 01 — 概述与架构

## 1. 本模板的本质定义

这是一个**功能完备、开箱即玩的商业级 JRPG**（在 `project.godot` 中的内部代号为 "Taos Game Maker"），并附带了一个**量身打造的可视化内容编辑器**。它不是一个抽象简陋的框架，而是一个各系统完全打通的成型游戏，旨在让开发者能够复用 **80% 到 90% 的底层引擎**（战斗、地牢探索、对话、背包、存档与角色成长），并将**创意内容**（世界观剧情、怪物、地图关卡、美术立绘与音乐）完全替换为您自己的作品。

### 4 大独立玩法支柱 + 1 个全局系统基石
- 🗺️ **大地图 (World)**：3D 俯视角大世界、资源采集、野外扎营烹饪、船只出海 (`TabWorld3D.gd`)。
- 🏰 **地牢 (Dungeons)**：第一人称 3D 网格地牢爬行，6 大探索技能解谜 (`ViewDungeon.gd`)。
- ⚔️ **战斗 (Combat)**：JRPG 经典回合制，ATB 行动条、行动点 (AP) 技能排队与连招协同 (`ViewCombat.gd`)。
- 📖 **叙事 (Narrative)**：视觉小说、分支对话图、城镇建筑、NPC 交互与剧情任务 (`ViewPlace.gd`)。
- ⚙️ **全局系统**：装备经济、商业店铺、成就系统、数值平衡 (`Autoloads`)。

---

## 2. 技术栈架构

- **游戏引擎**：Godot 4.3+，GDScript，`mobile` 渲染模式，原生 3D 物理引擎。
- **目标平台**：PC 桌面端 (Windows, macOS, Linux) 与 移动端 (Android, iOS)。
- **内容编辑器**：Vue 3（通过 CDN 加载，**零编译步骤**，无需 npm/node 即可直接运行）。
- **本地服务**：原生 Python 3 标准库 (`editor/serve.py`)。
- **数据持久化**：`data/` 目录下的纯文本 JSON 文件。

---

## 3. Godot 自动加载单例 (Autoloads)

在 `project.godot` 中的 `[autoload]` 声明，可在任意脚本中全局调用：
- `Locale` (`scripts/autoload/Locale.gd`)：原生管理 7 种语言（中文、英语、西班牙语、法语、意大利语、德语、日语）、字体缩放与色盲辅助模式。
- `Design` (`scripts/autoload/Design.gd`)：全量加载、解析并高速缓存 `data/` 中的全部 JSON 数据。
- `ExplorationSkills` (`scripts/autoload/ExplorationSkills.gd`)：地牢 6 大解谜工具的逻辑与状态。
- `GlobalState` (`scripts/autoload/GlobalState.gd`)：玩家属性、金币、背包、装备与剧情 Flag。
- `GlobalEvents` (`scripts/autoload/GlobalEvents.gd`)：完全解耦的全局发布/订阅事件总线。
- `SaveManager` (`scripts/autoload/SaveManager.gd`)：游戏存档的序列化与加密存储。
- `QuestManager` (`scripts/autoload/QuestManager.gd`)：主支线任务状态机与过场动画触发器。
