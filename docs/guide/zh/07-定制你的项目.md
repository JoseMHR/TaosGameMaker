# 07 — 定制你的项目（商业化实战路线图）

## 阶段 0 — 商业定位与发布模式

### 两种核心分发形态
- **形态 A：作为高级商用模板 / RPG 游戏制作器出售 (itch.io, Gumroad, Asset Store)**：
  将包含 Godot 4 源码与 `editor/` 编辑器的完整仓库打包。购买者将获得一套开箱即用的工业级 JRPG 引擎与无代码可视化编辑器，本套 7 国语言用户指南即可直接作为您交付给客户的官方产品手册。
- **形态 B：作为独立商业游戏发行 (Steam, Nintendo Switch, Google Play, iOS, 独立站)**：
  将 `data/` 中的演示剧情与 `assets/` 中的素材全面替换为您自己的原创 IP。从 Godot 导出最终发行包时 (`export_presets.cfg`)，所有开发辅助模块 (`editor/`, `tools/`, `docs/`) 会被**全自动剥离**，输出极致精简的纯净安装包。

---

## 阶段 1 — 基础品牌重塑

1. **游戏标题**：在 `project.godot` 中修改 `[application] config/name="您的游戏名"`。
2. **应用图标**：替换项目根目录下的 `icon.png`。
3. **开屏 Splash**：替换 `assets/common/boot_splash.png`。
4. **鸣谢清单**：更新 `Credits.txt`，补齐开发团队并保留引用的开源第三方资产许可证。
5. **语言设定**：在 `scripts/autoload/Locale.gd` 中设置游戏启动默认语言（例如中文设为 `var current_locale = "zh"`）。

---

## 阶段 2 至 8 — 核心内容构建

1. **主线大纲**：在 `data/quests.json` 中规划主线状态流与线索提示。
2. **职业与技能**：在 Web 编辑器【职业】与【技能】面板定制职业转职树与技能效果。
3. **怪物图鉴**：在【敌人】面板构建怪物，并在 **Combat Sandbox** 中即时开打调参。
4. **绘制大地图**：在【地图】面板挥洒地形，并在【城镇工作台】组装特色建筑与常驻商人。
5. **设计地牢**：在【地牢】面板拼接 3D 网格谜题，使用漫游模拟器验证通路。
6. **编织剧情**：在【NPCs】面板搭建多语言分支对话图。
