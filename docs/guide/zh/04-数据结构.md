# 04 — 数据结构 (`data/`)

所有游戏数据均以纯文本 JSON 形式存储在 `data/` 目录下：

- **`kind: 'doc'`**：单个 JSON 文件保存完整字典（如 `professions.json`, `config.json`, `quests.json`）。
- **`kind: 'perId'`**：每个 ID 对应一个独立 JSON 文件（如 `enemies/<id>.json`, `npcs/<id>.json`, `dungeons/<id>.json`）。

---

## 1. 原生 7 语言国际化字典

所有展示给玩家的文本均存储为包含 7 个官方语言键的字典结构：
- `zh`（简体中文）
- `en`（英语）
- `es`（西班牙语）
- `fr`（法语）
- `it`（意大利语）
- `de`（德语）
- `ja`（日语）

示例：
```json
"text": {
    "zh": "欢迎来到酒馆！",
    "en": "Welcome to the tavern!",
    "es": "¡Bienvenido a la taberna!",
    "fr": "Bienvenue à la taverne !",
    "it": "Benvenuto alla taverna!",
    "de": "Willkommen in der Taverne!",
    "ja": "酒場へようこそ！"
}
```

## 2. 奖励代币微语言 (`reward`)

广泛应用于 NPC 对话选项、事件触发器与成就系统中，由分号 `;` 分隔的键值对组成：

| 代币 (Token) | 语法示例 | 实际效果 |
|---|---|---|
| `gold` | `gold:±N` | 增加或扣除金币 |
| `xp` | `xp:N` | 给予角色经验值 |
| `heal` | `heal` | 全队生命值 (HP) 与法力值 (MP) 瞬间全满 |
| `damage` | `damage:N` | 造成非战斗伤害（最低保留 1 点生命，不会致死） |
| `item` | `item:ID=N` | 获得指定数量道具 |
| `-item` | `-item:ID=N` | 扣除指定数量道具 |
| `flag` | `flag:NAME` | 标记当前 NPC 的局部 Flag |
| `gflag` | `gflag:NAME` | 标记全局永久剧情 Flag |
| `questf` | `questf:STATE` | 驱动主线任务向后推进至该状态 |
| `prof` | `prof:ID` | 解锁并直接转职装备该职业 |
| `combat` | `combat:enemy_id[:level]` | 触发遭遇战 |
| `cine` | `cine:ID` | 播放指定剧情动画场景 |

## 3. 条件判断表达式 (`condition`)

底层由 Godot `Expression` 动态求值的逻辑表达式：
- `has_flag("X")` / `no_flag("X")`：NPC 局部 Flag 检查。
- `gflag("X")` / `has_gflag("X")`：全局剧情 Flag 检查。
- `has_item("id"[, qty])`：背包道具持有判定。
- `gold >= 100`：金币持有量门槛。
- `quest == "dam_opened"`：主线任务当前阶段匹配。
