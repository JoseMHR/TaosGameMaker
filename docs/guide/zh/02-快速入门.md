# 02 — 快速入门

## 1. 环境准备

- **Godot Engine 4.3+**
- **Python 3.8+**
- 现代浏览器（Chrome、Edge 或 Firefox）

---

## 2. 在 Godot 中启动游戏

1. 打开 Godot 4，点击 **导入 (Import)**，选择本项目的根目录（包含 `project.godot` 的文件夹）。
2. 初次打开时，Godot 会自动导入所有纹理和 3D 模型。
3. 点击右上角的 ▶️（或按 `F5`），即可进入游戏主菜单。

---

## 3. 运行本地 Web 编辑器

在项目根目录下打开命令行终端：

```bash
python editor/serve.py
```

终端启动后会自动在默认浏览器中打开 `http://localhost:8000/`。

常用命令参数：
```bash
python editor/serve.py --port 8123      # 使用指定端口
python editor/serve.py --no-open        # 启动时不自动弹出浏览器
```

---

## 4. 推荐的日常开发工作流

1. 保持 `python editor/serve.py` 在后台终端运行。
2. 在浏览器编辑器中修改数据（怪物数值、关卡地图、NPC 剧情），点击 **保存 (Save)**。
3. 切换回 Godot，点击 ▶️ 立即测试修改效果（无需重启 Web 服务）。
4. 在提交 Git 变更前，运行自动化校验脚本：
   ```bash
   python tools/validate_data.py
   ```
   确保全库没有产生悬空的无效 ID 引用。
