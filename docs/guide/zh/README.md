# ⚔️ JRPG Complete Template & Engine — 简体中文用户指南

> **欢迎使用专为 Godot 4 打造的专业级 JRPG 游戏模板与引擎。**  
> 本项目将一个完整的商业级游戏（3D 俯视角大地图、第一人称网格地牢爬行、回合制战术战斗以及视觉小说叙事系统）与一个**专用的本地可视化 Web 编辑器**深度结合，让您无需编写一行底层代码即可创建、修改并平衡属于您自己的完整游戏。

---

## ⚡ 快速上手（3分钟内启动）

无需配置数据库，无需复杂的构建编译步骤，即开即用：

### 1. 环境要求
- **Godot Engine 4.3+**（Standard 版或 .NET 版均可）。
- **Python 3.8+**（macOS/Linux 已预装；Windows 用户可在 [python.org](https://www.python.org/) 下载）。

### 2. 在 Godot 中打开与游玩
1. 打开 **Godot Engine**，点击 **导入 (Import)**。
2. 选择本目录下的 `project.godot` 文件。
3. 点击 **运行项目 (Run Project)**（或按快捷键 `F5`），即可进入主菜单！
   - 如需快速体验全部内容，可在主菜单中选择 **调试模式 / 测试大厅 (Debug Mode / Test Room)**。

### 3. 启动本地可视化内容编辑器
内容编辑器是一个轻量级的本地 Web 应用，无需 `npm` 依赖，无需编译：
1. 在项目根目录下打开终端。
2. 执行以下命令：
   ```bash
   python editor/serve.py
   ```
3. 在浏览器中打开：
   👉 **[http://localhost:8000](http://localhost:8000)**

在 Web 编辑器中保存的任何修改（新怪物、地图、对话等）**都会即时同步到 Godot，无需重启游戏引擎**。

## 🎮 本模板包含什么？

### 🗺️ 4 大无缝集成的核心游戏支柱
1. **3D 俯视角大世界 (Overworld)**：网格地块系统、战争迷雾、生物群系、环境气候危险、持久化世界状态变化（可砍伐的树木、可粉碎的巨石、可建造的营地）与可驾驶的船只。
2. **第一人称地牢探索 (3D Dungeon Crawler)**：经典第一人称步进式网格地牢，配备动态小地图、钥匙门禁、机关谜题、宝箱与 Boss 战。
3. **回合制战术战斗**：完整的 JRPG 战斗系统，支持元素克制计算、异常状态、ATB 行动条、行动点 (AP) 技能排队、职业协同技能以及动态镜头特写。
4. **视觉小说叙事系统**：带有决策树的分支对话、生动的立绘表情、反应式背景音乐、主支线任务追踪以及持久化全局剧情 Flag。

### 🛠️ "No-Code" 可视化 Web 编辑器
浏览器内的完整游戏设计工作台：
- **3D 世界地图编辑器**：一键绘制地形、放置城镇、地牢入口、采集资源、野怪与宝箱。
- **地牢关卡设计师**：设计多层 3D 网格关卡，实时纹理预览，步进式通关漫游模拟器 (*DungeonWalkthroughModal*)。
- **敌人与技能工坊**：调整基础属性、AI 行为树、掉落表，并通过内置的 **Combat Sandbox (实时战斗沙盒)** 直接在浏览器中对战调优。
- **对话与剧情树编辑器**：可视化节点图编辑器 (*NpcGraphEditor*)，分支条件配置，配备即时视觉小说模拟器 (*VnSimulator*)。
- **天赋树、职业与技能协同**：全方位的角色成长数值平衡。
- **一键创建向导 (Wizards)**：一键快速生成地牢骨架、任务链、道具及带 NPC 的兴趣点 (POI)。
- **原生 7 语言国际化**：中文、英语、西班牙语、法语、意大利语、德语与日语深度集成，游戏内秒级实时切换。

### 🧪 调试大厅与全要素测试场
- 包含 `data/world_test.json` 专用测试世界，划分为 8 大主题展馆，**100% 集中展示了全游戏所有 POI (162个)、城镇 (4座)、地牢 (13座) 以及全部敌人 (41种)**。

## 💡 核心设计信条

> **“凡是能写在 JSON 里的，就绝不写死在代码里。”**

使用本模板打造属于您的游戏，核心操作就是在保持底层高性能 GDScript 引擎稳定的前提下，**通过 Web 可视化编辑器修改或替换 `data/` 中的 JSON 文件**。
