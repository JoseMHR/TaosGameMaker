# 06 — 美术、音频与资源

## 1. 资产目录规划 (`assets/`)

| 目录路径 | 存放内容说明 |
|---|---|
| `assets/combat/` | 职业立绘 (`character/`), 怪物立绘 (`enemies/`), 战斗背景 (`bg/`), 技能图标 (`skills/`), 战斗特效 |
| `assets/common/` | Cinzel 矢量字体 (`fonts/`), 道具图标 (`items/`), 全部 3D 模型 (`models/`), 全局 BGM 与音效 |
| `assets/dungeon/` | 地牢墙体、地面与天花板材质贴图 (`textures/`) |
| `assets/vn/` | 16:9 全景场景图 (`bg/`) 与 NPC 立绘 (`npcs/`) |
| `assets/world/` | 大地图地块材质 (`map/`) |

---

## 2. 规范分辨率与格式要求

| 资产类型 | 推荐文件格式 | 标准参考分辨率 | 关键规范 |
|---|---|---|---|
| **场景背景 / POI 图** | PNG / JPG | **1024×576** (16:9 比例) | 全屏展示，人物可直接绘制在场景画卷中 |
| **战斗场景背景** | PNG / JPG | **1024×576** (16:9 比例) | 横屏竞技场 |
| **立绘 (NPC/怪物/主角)** | PNG 32-bit RGBA | **512×512** | 必须具备透明通道，无背景白边 |
| **道具 / 技能图标** | PNG 32-bit RGBA | **128×128** 或 **256×256** | 方形图标 |
| **3D 建筑与角色模型** | `.glb`（优先）或 `.obj` | 缩放比例 1.0 = 1 个 Godot 长度单位 | 放入 `assets/common/models/` |
| **背景音乐 (BGM)** | `.ogg` / `.mp3` / `.wav` | 立体声，支持平滑循环 | `AudioManager.gd` 统一调度 |

---

## 3. 图像自动化透明抠图工具 (`tools/process_image.py`)

如果您使用 AI 绘画工具生成了带有纯色底色的立绘：

```bash
pip install Pillow
python tools/process_image.py input.jpg output.png --type sprite
```
该工具会自动进行泛洪算法背景扣除，并带有抗白边平滑羽化效果。也可直接在 Web 编辑器的媒体库中点击“处理图片”按钮在线调用。
