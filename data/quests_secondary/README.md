# Misiones Secundarias / Modular Side Quests

Este directorio está reservado para almacenar misiones secundarias modulares del **Sistema Multi-Quest**.
Cada misión secundaria puede definirse en su propio fichero JSON: `<quest_id>.json`.

This directory is reserved for modular side quests within the **Multi-Quest System**.
