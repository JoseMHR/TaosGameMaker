Frequently Asked Questions

FAQ & Licensing

Everything you need to know about licensing, platform capabilities, and using Taos Game Maker for your own projects.

No programming is required for core game creation. You can design complete world maps, assemble 3D dungeons, write branching dialogue trees, configure monster stats, build questlines, and balance items entirely through the 45+ visual tools in the included No-Code Web Studio Suite.

If you are a programmer, the entire Godot 4 project is provided in clean, modular GDScript with zero hidden binary blobs, giving you complete freedom to extend, customize formulas, or write custom shaders.
Yes, 100% free, open source, and royalty-free. You can get Taos Game Maker directly from the official Godot Asset Store or download/clone it from GitHub at zero cost. You can create commercial games and sell them on Steam, itch.io, Google Play, Epic Games Store, or consoles, and you keep 100% of your revenue. You never owe royalties or licensing fees.
Taos Game Maker is 100% free and open-source. If the framework saves you time or empowers your game development journey, you can support continuous maintenance and new features with a voluntary donation via our PayPal Support & Donation page (one-click web payment or mobile QR scan).
The package includes:
  • Complete Godot 4.3+ Project Template: Ready to open, customize, and export.
  • Local Web Studio Suite: Over 45 visual tools (Map Editor, 3D Dungeon Piece Architect, Dialogue Node Graph, Combat Sandbox, Item & Quest Wizards, Media Library, and QA Validator).
  • Full Core Subsystems: 3D Overworld, 1st-Person Grid Dungeon Crawler, Turn-Based Tactical Combat, Visual Novel Dialogue System, and City Crafting/Gathering.
  • Multiplatform Export Presets: Pre-tuned configurations for Windows, Linux, macOS, Android (APK/AAB), and Web (HTML5).
  • Starter Assets: Base models, textures, interface graphics, sound effects, and music tracks.
Taos Game Maker includes tested and pre-configured export presets for:
  • Windows Desktop: 64-bit standalone executable (`.exe`).
  • Linux / X11: Native 64-bit binary (`.x86_64`), compatible with desktop Linux and Steam Deck (SteamOS).
  • macOS: Universal binary supporting both Intel and Apple Silicon (M1/M2/M3/M4).
  • Android: Standard APK and Google Play Store App Bundle (`.aab`).
  • Web (HTML5): Playable directly in browser via WebAssembly/WebGL.
Zero DRM, zero telemetry, zero subscriptions. Taos Game Maker is 100% free and open source. The local web studio and Godot engine run completely offline on your computer. You own the files forever.
Echoes of Truth (Ecos de la Verdad) is our full-length tactical RPG built 100% on top of Taos Game Maker. It serves as both a complete standalone game and a living, playable demonstration of the engine's capabilities. You can play it for free on itch.io.
The engine codebase and Web Studio suite are open source under the MIT License. You are free to use, modify, and build commercial or free games with zero royalties (attribution and preserving the copyright notice are required per MIT terms). The narrative intellectual property, universe lore, characters, and original art assets of Echoes of Truth and The Lazarus Saga remain proprietary © 2026 Taos World.

  • Plantilla completa para Godot 4.3+: Lista para abrir, personalizar y exportar.

Taos Game Maker incluye presets probados para:
