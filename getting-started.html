Quickstart Guide

Getting Started with Taos Game Maker

Get your first tactical RPG project running in less than five minutes. Taos Game Maker comes pre-configured with a complete Godot 4 project and an instant local web studio.

System Requirements

Component Requirement Notes
Godot Engine Version 4.3 or newer Standard official build (No .NET/C# build required; 100% pure GDScript & Compatibility/Forward+ renderer).
Python Version 3.8+ Used strictly by the local web studio server (editor/serve.py). Uses only built-in standard libraries (zero pip dependencies).
Web Browser Any modern browser Chrome, Firefox, Safari, Edge, or Brave for accessing the local visual editing suite at localhost:8000.
Operating System Windows, Linux, or macOS Fully cross-platform development environment and export capabilities.
💡
Zero Configuration Hassle: You do NOT need to install node.js, npm, docker, or external databases. The entire editing suite runs locally out of the box with standard Python and Godot.

The 3-Step Setup Workflow

Getting Taos Game Maker up and running takes three straightforward actions:

1

Clone or Download

Clone the repository via git clone https://github.com/JoseMHR/TaosGameMaker.git or download and extract the repository ZIP.

2

Open in Godot 4

Launch Godot 4.3+, click Import, browse to the directory, select project.godot, and open the project.

3

Launch Web Studio

Double-click start_editor.bat (Windows) or execute ./start_editor.sh (Linux/Mac) to launch the visual suite.

Launching the No-Code Web Studio

The visual suite runs a lightweight local server that hosts the 45+ visual editing tools in your web browser.

Terminal Command (Linux / macOS / Windows) CLI 
# On Windows: Double-click start_editor.bat
# Or run from terminal:
python editor/serve.py

# Output:
# [Taos Game Maker] Server started at http://localhost:8000/
# Press Ctrl+C to stop.

Your default web browser will automatically open to http://localhost:8000, presenting the complete Taos Game Maker design workspace.

First Steps in the Studio

The studio workspace is categorized into intuitive design suites:

  • Overworld Map Designer: Place terrain tiles, interactive POIs, monsters, dynamic weather triggers, and chest locations visually.
  • 3D Dungeon Architect: Assemble grid dungeon floors, place doors, torch fixtures, traps, and boss arenas in a 2D/3D hybrid viewport.
  • Tactical Combat Sandbox: Test enemy encounters, test turn order math, and balance skill synergies without launching Godot.
  • Visual Novel & NPC Graph: Connect dialogue branches with node graphs, configure facial portraits, and trigger quest conditions.
  • Database Managers: Dedicated visual managers for items, abilities, professions, achievements, world transforms, and music tracks.

Testing Your Game in Godot

To test changes in real time, simply click the «Test in Godot» button in the Web Studio toolbar, or press F5 inside the Godot editor.

ℹ️
Instant Synchronization: Whenever you save changes in the web editor, the modified JSON databases are updated on disk. Godot's autoload data managers load these definitions directly upon startup.

Guía de Inicio Rápido

Primeros Pasos con Taos Game Maker

Pon en marcha tu primer proyecto de RPG táctico en menos de cinco minutos. Taos Game Maker viene preconfigurado con un proyecto completo de Godot 4 y un estudio web local listo para usar.

Requisitos del Sistema

Componente Requisito Notas
Godot Engine Versión 4.3 o superior Compilación oficial estándar (sin necesidad de .NET/C#; 100% GDScript puro y renderizador Compatibility/Forward+).
Python Versión 3.8+ Utilizado exclusivamente por el servidor del estudio web local (editor/serve.py). Solo librerías estándar integradas (cero dependencias de pip).
Navegador Web Cualquier navegador moderno Chrome, Firefox, Safari, Edge o Brave para acceder a la suite de diseño visual en localhost:8000.
Sistema Operativo Windows, Linux o macOS Entorno de desarrollo y capacidades de exportación totalmente multiplataforma.
💡
Sin Complicaciones de Configuración: NO necesitas instalar node.js, npm, docker ni bases de datos externas. Toda la suite de herramientas funciona en local desde el primer momento con Python y Godot estándar.

El Flujo de Instalación en 3 Pasos

Poner en funcionamiento Taos Game Maker solo requiere tres acciones directas:

1

Clonar o Descargar

Clona el repositorio con git clone https://github.com/JoseMHR/TaosGameMaker.git o descarga y descomprime el archivo ZIP.

2

Abrir en Godot 4

Abre Godot 4.3+, pulsa en Importar, navega a la carpeta del proyecto, selecciona project.godot y abre el proyecto.

3

Iniciar el Estudio Web

Haz doble clic en start_editor.bat (Windows) o ejecuta ./start_editor.sh (Linux/Mac) para abrir la suite visual.

Iniciar el Estudio Web Visual

La suite visual ejecuta un servidor local ultraligero que sirve las más de 45 herramientas de diseño directamente en tu navegador.

Comando de Terminal (Linux / macOS / Windows) CLI 
# En Windows: Doble clic en start_editor.bat
# O ejecutar desde consola:
python editor/serve.py

# Salida:
# [Taos Game Maker] Server started at http://localhost:8000/
# Press Ctrl+C to stop.

Tu navegador predeterminado se abrirá automáticamente en http://localhost:8000, mostrando el entorno completo de trabajo de Taos Game Maker.

Primeros Pasos en el Estudio

El espacio de trabajo está organizado en módulos de diseño intuitivos:

  • Diseñador de Overworld: Coloca casillas de terreno, puntos de interés (POIs), enemigos, disparadores climáticos y cofres de forma visual.
  • Arquitecto de Mazmorras 3D: Construye plantas de mazmorra por casillas, coloca puertas, antorchas, trampas y salas de jefes en un visor híbrido 2D/3D.
  • Sandbox de Combate Táctico: Prueba encuentros con enemigos, simula el orden de turnos y calibra las habilidades sin abrir Godot.
  • Novela Visual y Grafo de Diálogos: Conecta ramas narrativas mediante nodos visuales, asigna retratos de personajes y evalúa condiciones de misiones.
  • Gestores de Bases de Datos: Editores dedicados para objetos, habilidades, clases, logros, transformaciones de mundo y temas musicales.

Probar tu Juego en Godot

Para comprobar los cambios en tiempo real, simplemente pulsa el botón «Probar en Godot» en la barra del Estudio Web, o presiona F5 en el editor de Godot.

ℹ️
Sincronización Instantánea: Cada vez que guardas en el editor web, los archivos JSON correspondientes se actualizan en disco al momento. Los gestores Autoload de Godot leen estas definiciones directamente al arrancar la escena.
